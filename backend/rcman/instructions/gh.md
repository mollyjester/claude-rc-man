## GitHub

- `gh` is installed and uses the person's GitHub token, when they have stored one.
  Use `gh` for GitHub work (issues, pull requests, the API), whatever other
  instructions say about using GitHub MCP tools instead.
- `gh auth status` names no account. That's expected. `gh api user` shows whose
  token it is. If gh is refused, the person needs to store or renew their token.
