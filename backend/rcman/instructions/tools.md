## Tools

- The image is Ubuntu, with `git`, `gh`, `curl`, `make`, `python3` (`python3 -m venv`
  makes a venv with pip), `tar`, `xz`, `zip`, `unzip`, and `podman`/`docker`.
- Install anything else with `apt-get` (as root, the default image's user), which lasts
  only as long as "This workspace" above says.
